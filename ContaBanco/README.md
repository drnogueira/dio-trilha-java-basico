# Projeto de Conta Bancária Simulada

Este projeto tem como objetivo simular o funcionamento básico de uma conta bancária, permitindo a interação com o utilizador através do terminal/console. O programa oferece funcionalidades como exibição do saldo, depósito e saque de valores, além de uma opção para encerrar o programa.

## Funcionalidades

- **Exibição do saldo:** Mostra o saldo atual da conta bancária.
- **Depósito:** Permite ao utilizador realizar um depósito na conta.
- **Saque:** Permite ao utilizador realizar um saque da conta.
- **Encerramento do programa:** Opção para terminar o programa com uma mensagem de despedida.

## Tecnologias Utilizadas

- **Java:** Linguagem de programação utilizada para o desenvolvimento do projeto.
- **Console/Terminal:** Interface de utilizador para interação com o programa.

## Como Executar

### Pré-requisitos

1. **Java:** Certifique-se de que o Java está instalado no seu sistema. Caso não tenha o Java instalado, pode obtê-lo [aqui](https://www.java.com/en/download/).
   
2. **Ambiente de Desenvolvimento:** Pode utilizar qualquer editor de código, como o [Visual Studio Code](https://code.visualstudio.com/download), [IntelliJ IDEA](https://www.jetbrains.com/idea/download/?section=windows), ou [Eclipse](https://eclipseide.org/).

### Passos para execução

1. Clone o repositório para o seu computador:

    ```bash
    git clone https://github.com/drnogueira/dio-trilha-java-basico.git
    ```

2. Aceda à pasta do projeto:

    ```bash
    cd nome_do_projeto
    ```

3. Compile o código Java:

    ```bash
    javac ContaTerminal.java
    ```

4. Execute o programa:

    ```bash
    java ContaTerminal
    ```

### Exemplo de Execução

O programa exibirá um menu interativo com as opções:

--- Menu ---

Exibir Saldo  
Depositar  
Sacar  
Sair  

Com base na opção escolhida, o programa executará a ação correspondente.
